¿Qué es Gunpla Scrapper Chile?

Esta herramienta no solo permite realizar un seguimiento histórico de productos mediante scraping automatizado, sino que ofrece un catálogo global estandarizado que unifica las publicaciones de distintas tiendas bajo un mismo modelo. Con esa base, los usuarios pueden visualizar las fluctuaciones de precio de cada modelo mediante gráficos interactivos, filtrar el catálogo por grado, y comparar de un vistazo qué tienda ofrece el mejor precio en cada momento.

Del otro lado, el equipo administrador cuenta con un panel de control dedicado para gestionar el catálogo: fusionar productos duplicados, ocultar publicaciones, y monitorear el estado de cada scraper y su disponibilidad por tienda.

Stack Técnico

El proyecto está construido íntegramente en Python, con un enfoque simple y mantenible:

Python Flask Jinja2 BeautifulSoup SQLite APScheduler Chart.js

Flask expone el sitio y el panel administrativo, Jinja2 arma las vistas, BeautifulSoup se encarga de la extracción de datos desde las tiendas objetivo, y APScheduler orquesta las corridas automáticas de scraping dos veces al día. Todo el historial de precios queda persistido en SQLite y se grafica con Chart.js en el detalle de cada producto.

Uso Ético y Responsable

Este proyecto fue desarrollado con fines educativos y de análisis personal. Como único responsable de la extracción de datos, me comprometo a respetar las políticas de uso de los sitios web objetivo y a no saturar sus servidores con peticiones excesivas.

En línea con eso, los módulos de recolección de este proyecto incluyen pausas (time.sleep) entre página y página durante el scraping, para asegurar un comportamiento respetuoso con el tráfico de red de cada tienda y no comportarse como un bot agresivo.
